# LIVING_ml-guide

住宅のマニュアルサイト更新制作法のファイルを管理するリポジトリです。  
作業メモと更新内容を一元化するため、この README に記録を残します。

## ディレクトリ構成

- `css/` : スタイル関連
- `js/` : JavaScript 関連
- `images/` : 画像アセット
- `desktop/` : デスクトップ向けファイル
- `mobile_fast/` : モバイル（高速回線想定）向けファイル
- `mobile_slow/` : モバイル（低速回線想定）向けファイル
- `ml-guide/` : 参照用ガイド・依存パッケージ群

## 更新記録のルール

- 新しい記録は先頭に追記する
- 1 行目に日付、2 行目以降に変更内容を箇条書きで記載する
- 可能であれば「何を」「なぜ」を短く書く
